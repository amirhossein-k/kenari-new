# ☕ کافه کناری · نسخه ۲ (Next.js 15 + MongoDB)

منوی دیجیتال و سفارش از سر میز برای کافه‌رستوران، همراه با پنل مدیریت کامل و اعلان لحظه‌ای سفارش‌ها.
این نسخه دمو است و **درگاه پرداخت ندارد**؛ سفارش مستقیم برای پنل ادمین ثبت می‌شود.

## امکانات
**سایت مشتری**
- صفحه اصلی با هیرو، محبوب‌ترین‌ها، مراحل سفارش و درباره ما
- منو با تفکیک کافه/رستوران، جستجو، تب‌های چسبان با اسکرول‌اسپای، مودال جزئیات محصول
- لینک اختصاصی هر میز: `/menu/table/5` (شماره میز خودکار روی سفارش ثبت می‌شود)
- سبد خرید کشویی (ذخیره در localStorage)، ثبت سفارش سرو در محل / بیرون‌بر
- صفحه پیگیری زنده‌ی وضعیت سفارش (`/order/K-1001`)
- کاملا ریسپانسیو، راست‌به‌چپ، فونت وزیرمتن، انیمیشن‌های نرم

**پنل مدیریت** (`/admin`)
- داشبورد: فروش امروز، سفارش‌های در انتظار، نمودار ۷ روز، پرفروش‌ها
- محصولات: افزودن / ویرایش / حذف، تخفیف، برچسب، موجود/ناموجود، ویژه، آپلود تصویر
- دسته‌بندی‌ها: افزودن / ویرایش / حذف / مخفی‌کردن، آیکون و بخش
- سفارش‌ها: فیلتر وضعیت، جستجو، تغییر وضعیت مرحله‌به‌مرحله، جزئیات کامل
- اعلان سفارش جدید: زنگوله با شمارنده، توست، صدای هشدار، نوتیفیکیشن مرورگر، شمارنده در عنوان تب
- تنظیمات سایت: نام، شعار، آدرس، ساعت کاری، بنر، باز/بسته بودن سفارش‌گیری، لینک میزها
- دکمه بازنشانی داده‌های دمو

## اجرا
```bash
npm install
cp .env.example .env.local   # و MONGODB_URI را تنظیم کنید
npm run dev
```
- دیتابیس اولین بار که خالی باشد **خودکار** با ۷ دسته، ۱۹ محصول و ۳ سفارش نمونه پر می‌شود.
- ورود ادمین: `http://localhost:3000/admin` با `admin / admin123` (قابل تغییر در `.env.local`).

## دیپلوی روی Vercel
1. یک کلاستر رایگان در MongoDB Atlas بسازید و در Network Access آی‌پی `0.0.0.0/0` را مجاز کنید.
2. متغیرهای `MONGODB_URI`، `JWT_SECRET`، `ADMIN_USERNAME`، `ADMIN_PASSWORD` را در Vercel تنظیم کنید.
3. Deploy.

## ساختار
```
src/
  app/(site)/        صفحات مشتری (خانه، منو، میز، checkout، پیگیری)
  app/admin/         ورود و پنل مدیریت
  app/api/           API عمومی (menu, orders) و ادمین (api/admin/*)
  components/        کامپوننت‌های سایت، ادمین و UI
  lib/               اتصال دیتابیس، احراز هویت، داده نمونه، توابع کمکی
  models/            مدل‌های Mongoose: Category, Product, Order, Notification, Setting
  middleware.ts      محافظت از /admin و /api/admin با JWT
```

> نکته: اعلان‌ها با polling هر ۶ ثانیه کار می‌کنند تا روی Vercel (Serverless) هم بدون سرویس اضافه جواب بدهند.
